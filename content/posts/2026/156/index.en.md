Accounting for advanced users - PTA

Again about personal finances. I've been tinkering with this for a long time. Right now I keep basic account and balance tracking, and I'm trying to evaluate investments. For my modest investment affairs, Google Sheets is more than enough, but for main bookkeeping, Excel has started to annoy me.

First, some context. I have about 20 different accounts in use in three currencies. New accounts appear from time to time, and some become irrelevant. For spreadsheets this is not a very pleasant story. Previously I solved these problems by splitting spreadsheets by year, but today I decided to try another approach using more advanced tools. Namely, hledger.

Its main idea is managing personal finances through plain text files. I started simply: I created one plain text journal and entered the current balances. In fact, this file is the database, and through the CLI tool you can build all sorts of analytical reports and more. There are a lot of other features too, but I haven't mastered them yet.

In short, I'll be testing it, and in a couple of months I'll report back on how it compares to Excel.
